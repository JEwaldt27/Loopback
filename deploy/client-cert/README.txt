Loopback - trust the app on this PC (one time, no admin needed)
================================================================

Loopback is served securely over https on your network. Before your browser
will open it without a warning (and before file exports will download), this PC
needs to trust Loopback's certificate. This is a one-time, 30-second step.

HOW TO RUN
----------
1. Keep both files in this folder together:
       install-cert.bat
       LoopbackRootCA.crt
2. Double-click  install-cert.bat
3. When it says "Success!", fully close your browser and reopen it.
4. Go to:  https://192.168.1.200:5052

That's it. No administrator rights are required.

NOTES
-----
- Chrome and Edge work immediately after step 3.
- Firefox only: open about:config and set
  security.enterprise_roots.enabled  to  true
- If Windows SmartScreen warns about the .bat, choose "More info" -> "Run anyway"
  (it only imports the certificate; it makes no other changes).

(For the admin who set this up: LoopbackRootCA.crt is generated by
deploy/gen-cert.sh. It is the PUBLIC root certificate and is safe to share. The
matching private key, rootCA.key, must NEVER be distributed.)
